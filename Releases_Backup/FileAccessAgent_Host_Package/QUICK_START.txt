========================================================================
   PCAccess - FileAccessAgent (Host PC Folder Sharing Service)
========================================================================
Server URL : https://remote.primaryportal.co.uk

HOW TO PAIR:
1. Double-click 'run.bat' on the computer where physical folders are located.
2. Note the 6-Digit Pairing Code displayed on the console (e.g. 582-194).
3. Log in to the Admin Web Portal:
   https://remote.primaryportal.co.uk/Admin/DeviceFolders
4. Click 'Pair Device' and enter the 6-digit code.
5. Your machine is now securely paired and ONLINE!

24x7 UNATTENDED BACKGROUND SERVICE:
- Right-click 'install-service.bat' and select 'Run as Administrator'.
- The agent will automatically start on PC boot and run silently in background.
