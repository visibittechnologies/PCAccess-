1. Overview: What is FileAccessAgent?

FileAccessAgent is a secure background service that runs on the Host PC / Office Server where company files physically reside.

Key Architecture: Similar to TeamViewer or AnyDesk, it establishes an outbound-only WebSocket connection via SignalR to https://remote.primaryportal.co.uk. It requires no public IP, no static IP, and no router port-forwarding.

2. Pairing Workflow (Step-by-Step)

1 Run Agent: Double-click run.bat on the Host PC.

2 View 6-Digit PIN: A temporary 6-digit pairing code (e.g., 582-194) appears on the console, valid for 15 minutes.

3 Pair via Web Portal: Log in to the Admin Dashboard (https://remote.primaryportal.co.uk/Admin/DeviceFolders) and submit the 6-digit code.

4 Device Becomes ONLINE: A cryptographic token binds the device permanently. The web dashboard will now show the device as ONLINE.

5 Assign Folders: Register local physical paths (e.g. D:\CompanyFiles) and grant permissions to users.

3. Windows Service Controls (24x7 Unattended Operation)

Script Command Purpose

5. Frequently Asked Questions

Q1: Does UserLoginAgent require FileAccessAgent to be running?
No! UserLoginAgent will always mount Drive R: and display folder names even if the host PC is offline. However, browsing live real-time files inside those folders requires the host PC's FileAccessAgent to be online.
Q2: Can both agents run on the same computer?
Yes! If your computer is both the folder provider and you also want to mount R: drive as a user, both agents run side-by-side without conflict.
