1. भूमिका (Introduction & Core Philosophy)

इस गाइड का उद्देश्य यह है कि अगली बार जब भी आप कोई नया या मौजूदा प्रोजेक्ट (जैसे PCAccess) पहली बार Git और GitHub पर डालना चाहें, तो आप बिना किसी परेशानी, बिना पासवर्ड एरर और बिना अकाउंट कन्फ्यूजन के टर्मिनल / CMD या GitHub Desktop से 100% खुद कर सकें।

💡 सबसे महत्वपूर्ण बात: अगस्त 2021 से GitHub ने टर्मिनल में डायरेक्ट पासवर्ड (जैसे awebworld*123#) लेना बंद कर दिया है। Git अब Browser Login (OAuth) या Personal Access Token (PAT) से ही काम करता है।

2. स्टेजिंग से पहले: .gitignore की तैयारी (Most Critical Step)

किसी भी .NET / C# / Web प्रोजेक्ट को Git में डालने से पहले .gitignore फाइल बनाना जरूरी है, ताकि bin, obj, packages, और .vs जैसी भारी फाइलें गिट में न जाएँ और केवल ओरिजिनल कोड ही पुश हो।

# अपने प्रोजेक्ट रूट में .gitignore फाइल बनाएं और ये नियम रखें: [Bb]in/ [Oo]bj/ packages/ .vs/ *.user *.suo *.bak

3. पूरा टर्मिनल प्रोसेस: Step-by-Step Command Flow

1 प्रोजेक्ट फोल्डर में जाएँ (Navigate to Project)

कमांड प्रॉम्प्ट (CMD) या PowerShell खोलें और अपने प्रोजेक्ट डायरेक्टरी में जाएँ:

cd /d E:\Git\PCAccess

2 गिट रिपॉजिटरी शुरू करें (Initialize Git)

git init

यह आपके प्रोजेक्ट में एक छुपी हुई .git डायरेक्टरी बना देगा।

3 प्रोजेक्ट के लिए अपना नाम और ईमेल सेट करें (Local User Config)

अगर आपके PC पर पहले से कोई दूसरा गिट अकाउंट चल रहा है, तो --global इस्तेमाल न करें। केवल इस प्रोजेक्ट के लिए लोकल पहचान सेट करें:

git config user.name "Visibit Technologies" git config user.email "visibittechnologies@gmail.com"

4 मेन ब्रांच का नाम सेट करें (Set Default Branch to 'main')

git branch -M main

5 कोड फाइल्स को स्टेज करें और कमिट करें (Stage & Commit)

# सभी फाइल्स को ट्रैक करें (.gitignore के अनुसार फालतू फाइल्स छोड़ दी जाएँगी): git add . # पहला कमिट बनाएं: git commit -m "Initial commit: Project full codebase with documentation"

6 GitHub पर नई Repository बनाएं

  1. ब्राउज़र में जाएँ: https://github.com/new
  2. Repository name डालें (जैसे PCAccess)। (ध्यान रखें: नाम में गलती से dash - न लगे)
  3. Public या Private चुनें और "Create repository" पर क्लिक करें।

7 Remote Origin लिंक करें (⭐ Golden Rule for Multi-Account)

अगर आपके कंप्यूटर पर पहले से कोई दूसरा गिट अकाउंट (जैसे sonukr9525) सेव है, तो डायरेक्ट लिंक करने पर 403 Permission Denied आ सकता है।
इसका 100% सही समाधान: URL में अपने GitHub यूजरनेम का प्रीफिक्स लगाएँ:

# फॉर्मेट: https://<username>@github.com/<username>/<repo>.git git remote add origin https://visibittechnologies@github.com/visibittechnologies/PCAccess-.git

अगर पहले से गलत remote जुड़ गया हो, तो उसे इस कमांड से बदलें:

git remote set-url origin https://visibittechnologies@github.com/visibittechnologies/PCAccess-.git

8 गिटहब पर कोड पुश करें (Push to Remote)

git push -u origin main
स्क्रीन पर क्या होगा: पहली बार यह कमांड चलाने पर Git Credential Manager का ब्राउज़र पॉपअप खुलेगा। चूँकि आप ब्राउज़र में पहले से लॉगिन हैं, बस "Authorize" पर क्लिक करें। आपका कोड 100% सफलतापूर्वक पुश हो जाएगा!

4. मुख्य समस्याएं और उनके 1-मिनट समाधान (Troubleshooting Matrix)

समस्या / एरर कारण सटीक समाधान (Solution)
remote: Repository not found रिपॉजिटरी अभी GitHub पर नहीं बनी है या नाम में स्पेलिंग मिस्टेक है (जैसे PCAccess vs PCAccess-)। ब्राउज़र में exact URL चेक करें और कमांड चलाएं:
git remote set-url origin <correct_url>
Permission denied to <old_user> (HTTP 403) Windows Credential Manager में किसी दूसरे अकाउंट के क्रेडेंशियल्स कैश्ड हैं। Remote URL में यूजरनेम लगा दें:
https://visibittechnologies@github.com/...
Support for password authentication was removed टर्मिनल में अकाउंट का मुख्य पासवर्ड डाला गया है। ब्राउज़र ऑथराइज़ेशन पॉपअप का उपयोग करें या Personal Access Token (PAT) का इस्तेमाल करें।
fatal: not a git repository उस फोल्डर में Git इनिशियलाइज़ नहीं किया गया है। प्रोजेक्ट फोल्डर में जाकर git init चलाएं।

5. GitHub Desktop में उपयोग करने के नियम

नियम A: इसी कंप्यूटर पर (जहाँ कोड पहले से मौजूद है)

  1. GitHub Desktop खोलें।
  2. मेनू बार में जाएँ: File ➔ Add Local Repository... (शॉर्टकट: Ctrl + O)
  3. लोकल पाथ चुनें: E:\Git\PCAccess
  4. Add Repository पर क्लिक करें।
चेतावनी: इसी कंप्यूटर पर "Clone" न करें, नहीं तो वह "Folder already exists" का एरर देगा।

नियम B: नए कंप्यूटर पर या टीम मेंबर के सिस्टम पर

  1. GitHub Desktop खोलें और अपने अकाउंट से साइन-इन करें।
  2. File ➔ Clone Repository... पर क्लिक करें।
  3. लिस्ट में से PCAccess- चुनें और लोकल पाथ देकर Clone दबाएँ। पूरा प्रोजेक्ट डाउनलोड हो जाएगा।
