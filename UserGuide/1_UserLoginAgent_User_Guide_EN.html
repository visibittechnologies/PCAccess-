PCAccess — UserLoginAgent User Guide

Direct Desktop Remote Drive (R:) Access System for Employees & Administrators
English Edition Version 1.0 Desktop Client Windows .NET 4.8

1. Introduction & Overview

UserLoginAgent is a lightweight Windows desktop client designed for employees and administrators. It enables seamless access to authorized corporate shared folders directly inside Windows Explorer without requiring a web browser.

Key Highlight: Upon successful login, the application automatically mounts a virtual R: Drive ("Remote Drive") under "This PC" in Windows Explorer, making remote files accessible just like local files.

2. Quick Start: How to Log In (Step-by-Step)

1 Launch Agent: Double-click run.bat (or UserLoginAgent.exe).

2 Confirm Server URL: The prompt automatically defaults to: https://remote.primaryportal.co.uk. Simply press [ENTER].

3 Enter Credentials: Type your assigned Username / Email and Password (password is safely masked with asterisks ***).

4 Save Credentials: When asked "Remember credentials on this PC? (Y/n)", press Y for 1-click automatic login next time.

5 Explore R: Drive: Windows Explorer will automatically pop up, displaying R:\ ("Remote Drive") with all your assigned folders.

3. Interactive Console Keybindings Reference

While the agent console is active, press any of the following keys on your keyboard:

Key Command Description Action Performed
S Session Status Inspect session health Displays User ID, Name, Role (Admin/User), Drive R: mount state, folder counts, and server connectivity.
O Open Drive Browse Remote Drive Immediately opens Windows File Explorer directly into R:\.
R Refresh Folders Synchronize Permissions Re-queries the server and updates accessible folders in R: in real time without restarting the agent.
C Switch User Clear Saved Credentials Unmounts drive R:, clears stored password, and returns to the login prompt to allow logging in as another user.
L / Q / X Logout & Exit Clean Disconnect Cleanly unmounts virtual drive R: from Windows, notifies shell, and gracefully exits the application.
Ctrl + C Force Exit Emergency Termination Invokes shutdown hooks, dismounts R:, and safely closes the console window.

4. Batch Scripts for Non-Interactive Control

For convenience or background automation, pre-packaged batch scripts are provided in the folder:

Batch Script Equivalent CLI Command Function & Usage
run.bat UserLoginAgent.exe Launches the desktop agent in interactive mode.
status.bat UserLoginAgent.exe status Checks whether the agent process is running and whether drive R: is mounted without interrupting the session.
logout.bat UserLoginAgent.exe logout Safely unmounts drive R: and terminates any running agent process.
stop.bat UserLoginAgent.exe stop Alternative alias for logout.bat.

5. Role-Based Permissions Summary

  • Administrator (user_type_id = 1): Receives full visibility and access to all active registered company shared folders across all devices.
  • Standard User / Employee (user_type_id = 2): Only receives folders explicitly shared by the Administrator with can_view = 1 permissions.
