PCAccess — UserLoginAgent User Guide

Direct Desktop Remote Drive (R:) Access System for Employees & Administrators
Version 1.0 Desktop Client Windows .NET 4.8 Browser-Free Access

1. Introduction & Purpose (Agent Kya Hai?)

UserLoginAgent ek dedicated desktop console client hai jiske zariye company ke employees aur administrators bina web browser khole apne PC me direct shared folders ko access kar sakte hain.

Key Benefit: User jaise hi agent me apna Username/Email aur Password daal kar login karta hai, Windows Explorer ("This PC") ke andar virtual drive R: ("Remote Drive") appear ho jati hai aur uske permitted folders instantly browse karne ke liye tayar ho jate hain.

2. How It Works (Step-by-Step Workflow)

1 Launch Agent: UserLoginAgent\run.bat par double-click karein.

2 Enter Server URL: Website URL enter karein (Default: https://pcaccess.ourdemos.com/).

3 Enter Credentials: Apna Username/Email aur Password enter karein (Password security ke liye masked *** format me type hoga).

4 Remember Credentials: Y press karne par agli baar direct 1-click Enter se login ho jayega.

5 Auto-Mount R: Drive: Authenticate hote hi Windows Explorer automatically R:\ Drive open karega jisme sabhi permitted folders available honge.

3. Interactive Terminal Commands (Console me Key Reference)

Jab agent console window open ho, tab aap keyboard se direct in keys ko press karke actions execute kar sakte hain:

Key Command Name Meaning (Matlab) Exact Action (Kya Dabane Pe Kya Hoga)
S Session Status Current Session & Health Check Console me User ID, Name, Role (Admin/User), Drive R: Mount Status, Folders Count aur Server Connection live display karega.
O Open Drive Open Explorer Windows Explorer ko trigger karega aur screen par direct R:\ (Remote Drive) folder open kar dega.
R Refresh Folders Re-fetch Shared Folders Bina agent band kiye server se query karega aur agar Admin ne koi naya folder assign kiya hai to use R: me add kar dega.
C Switch User Clear Saved Login Current drive unmount karega, saved credentials delete karega aur doosre user (e.g. Rahul se Admin) login karne ke liye prompt dega.
L / Q / X Logout & Exit Clean Disconnect & Stop Virtual Drive R: ko Windows system se cleanly unmount karega, registry refresh karega aur application safely close ho jayegi.
Ctrl + C Force Exit Emergency Stop Shutdown hook call karke drive unmount karega aur instantly window band kar dega.

4. Batch Scripts Reference (Folder Level Commands)

Agar console window minimize ho ya background me chal rahi ho, to UserLoginAgent folder me ready-made batch scripts hain:

Script Name Equivalent CLI Command Description & Action
run.bat UserLoginAgent.exe Agent ko foreground interactive mode me start karta hai.
status.bat UserLoginAgent.exe status Running agent ko bina roke check karta hai ki process active hai ya nahi aur Drive R: mounted hai ya nahi.
logout.bat UserLoginAgent.exe logout Drive R: ko safely unmount karta hai aur background me chal rahe agent process ko band/terminate kar deta hai.
stop.bat UserLoginAgent.exe stop logout.bat ka alternate batch file jisse agent aur drive dono safely stop ho jate hain.

6. Role-Based Permissions (Admin vs User)

  • Admin (user_type_id = 1): Login karne par system me active sabhi shared folders automatically R: drive me appear hote hain.
  • User / Employee (user_type_id = 2): Login karne par sirf wahi folders dikhenge jisme Admin ne web portal se can_view = 1 assign kiya ho.
